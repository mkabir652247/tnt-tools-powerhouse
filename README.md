# TNT Tools Powerhouse

Create a modern, premium, fully responsive e-commerce website for a power tools and hardware brand called “TNT Tools”.

BUSINESS:

TNT Tools is an online store selling power tools, construction tools, workshop equipment, water pumps, drilling machines, cutting tools, and other professional hardware products.

BRAND STYLE:

- Primary colors: Black and Orange

- Use a dark, powerful, industrial aesthetic

- Primary background: Black / near-black

- Accent color: Strong construction orange

- Secondary colors: White, light gray, and dark charcoal

- The design should feel rugged, professional, trustworthy, and premium

- Avoid making it look cheap, overly colorful, or like a generic template

- Use bold typography and strong visual hierarchy

- Use subtle orange glow/gradient effects sparingly

- Add smooth hover effects and subtle animations

- Use high-quality product imagery with clean backgrounds

WEBSITE STRUCTURE:

1. HEADER / NAVIGATION

Create a sticky modern header containing:

- TNT Tools logo/name

- Home

- Shop

- Categories

- About Us

- Contact

- Search icon/input

- Wishlist icon

- Shopping cart icon

- Account icon

- A prominent “Shop Now” button

On mobile, use a clean hamburger menu.

2. HERO SECTION

Create a high-impact hero section with:

Headline:

“Power Your Work. Built to Perform.”

Supporting text:

“Professional power tools, water pumps, and reliable equipment for every job.”

Buttons:

- “Shop Now”

- “Explore Categories”

Show a large premium image/composition of professional power tools such as a cordless drill, angle grinder, impact driver, and water pump.

Add small trust indicators such as:

- Quality Tools

- Competitive Prices

- Reliable Products

- Fast Delivery

3. SHOP BY CATEGORY

Create attractive category cards for:

- Drill Machines

- Water Pumps

- Angle Grinders

- Cutting Tools

- Impact Tools

- Welding Machines

- Air Compressors

- Hand Tools

- Other Power Tools

Each category card should have an image, category name, short description, and hover animation.

4. FEATURED PRODUCTS

Create a product grid with professional e-commerce product cards.

Each card should include:

- Product image

- Product name

- Short specification

- Rating

- Price

- Previous price where applicable

- Discount badge

- “Add to Cart” button

- Wishlist button

- Quick View button

Example products:

- TNT Cordless Drill Machine 21V

- Heavy Duty Water Pump 1HP

- Professional Angle Grinder 850W

- Cordless Impact Driver

- Heavy Duty Electric Drill

- High Pressure Water Pump

- Cutting Machine

- Industrial Heat Gun

Use realistic placeholder products and images. Structure the product data so products can easily be replaced later.

5. SPECIAL OFFER / PROMOTIONAL BANNER

Create a bold orange-and-black promotional section:

“Power Deals. Better Prices.”

Text:

“Get professional-grade tools at competitive prices.”

Button:

“View All Deals”

Include a visually appealing power tool product image.

6. WHY CHOOSE TNT TOOLS

Create a section with 4–6 benefits:

- Reliable Quality

- Competitive Pricing

- Professional-Grade Tools

- Wide Product Range

- Fast Delivery

- Customer Support

Use modern icons and clean cards.

7. BEST SELLERS

Create another product carousel/grid showcasing the most popular products.

Include badges such as:

“Best Seller”

“Popular”

“Limited Stock”

8. ABOUT TNT TOOLS

Create a professional About section explaining:

“TNT Tools provides reliable power tools, construction equipment, water pumps, and workshop essentials for professionals, technicians, contractors, and DIY users.”

Emphasize:

- Quality

- Reliability

- Performance

- Value for money

Include a professional workshop/tool image.

9. CUSTOMER REVIEWS

Create a testimonials section with 3–4 customer reviews.

Example:

“Excellent build quality and very good performance. The drill works exactly as expected.”

— Ahmed R.

“Good product, competitive price, and quick delivery.”

— Usman K.

Use star ratings and customer initials/profile placeholders.

10. NEWSLETTER / CTA

Create a strong black/orange CTA section:

“Get the Latest Deals & New Tools”

Text:

“Subscribe to receive new product launches, exclusive offers, and special discounts.”

Include email input and “Subscribe” button.

11. FOOTER

Create a professional footer containing:

- TNT Tools logo/name

- Short company description

- Quick Links

- Shop Categories

- Customer Support

- Contact information

- Social media icons

- Newsletter signup

- Privacy Policy

- Terms & Conditions

- Shipping & Returns

E-COMMERCE FUNCTIONALITY:

Build the website as a real e-commerce interface, not just a static landing page.

Include:

- Product listing page

- Product detail page

- Search functionality

- Category filtering

- Price filtering

- Sorting

- Product ratings

- Add to cart

- Cart drawer/page

- Quantity controls

- Wishlist

- Checkout page

- Customer account UI

- Order summary

- Coupon/discount field

- Shipping information

- Payment method selection

- Order confirmation page

PRODUCT PAGE:

Create a detailed product page containing:

- Large product gallery

- Product name

- Rating

- Price

- Discount

- Availability

- Product description

- Specifications table

- Features

- Quantity selector

- Add to Cart

- Buy Now

- Related products

- Customer reviews

SEARCH & FILTERING:

Allow users to search products and filter by:

- Category

- Price

- Brand

- Rating

- Availability

- Product type

DESIGN DETAILS:

- Use black as the dominant color

- Use orange for CTAs, highlights, badges, active states, and important accents

- Use white/light gray for readable text

- Use rounded corners but keep them moderately sharp and industrial

- Use subtle shadows

- Use modern cards

- Use clean spacing

- Use large product photography

- Add micro-interactions to buttons and product cards

- Make the site feel fast and premium

- Avoid excessive animations

- Maintain excellent contrast and accessibility

TYPOGRAPHY:

Use a bold modern sans-serif font for headings and a clean readable sans-serif for body text.

RESPONSIVE DESIGN:

The website must be fully responsive and optimized for:

- Desktop

- Laptop

- Tablet

- Mobile

Make the mobile shopping experience especially clean and easy to use.

IMPORTANT:

Do not create a generic SaaS website or a simple template.

The final result should look like a professional, established power-tools e-commerce brand.

The visual identity should communicate:

POWER + DURABILITY + PROFESSIONALISM + TRUST.

Use realistic placeholder product data and images, but structure the application so products, prices, categories, images, and inventory can easily be replaced or connected to a backend later.

Build the complete website with reusable components and a clean, scalable structure.
